# PLP Python Week 6 — Loops Assignment

- times_table.py - Prints a user's multiplication table from 1 to 10.
- skip_counter.py - Prints even numbers from 0 to 20 and counts down from 10 to 0.
- loop_hospital.py - Fixes three broken loops using range(), while, and a running total.

An off-by-one error happens when a loop runs one time too many or one time too few. A useful range() habit is to remember that the stop value is not included. For example, use range(1, 11) when you want to print the numbers 1 through 10.
